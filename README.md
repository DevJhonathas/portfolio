## Funcionalidades

- **Página única** com as seções Início, Projetos, Sobre mim, Experiência e Tecnologias.
- **Tema claro e escuro.**
- **Projetos em cards**, cada um com sua própria página de detalhes.
- **Tecnologias interativas:** cada tecnologia abre uma descrição com "onde utilizei", ligando aos projetos em que foi usada.
- **Selo de disponibilidade** para vagas.
- **Contato rápido** por GitHub, LinkedIn, WhatsApp e e-mail.
- **Layout responsivo** e código organizado em componentes (navbar, footer etc.).

## Tecnologias

- **Stack:** Next.js, React, TypeScript e Tailwind CSS
- **Ferramentas:** Git e GitHub

## Projetos em destaque

| Projeto | Descrição | Stack |
|---|---|---|
| **Camada** | Calculadora de custos e preços para peças produzidas em impressão 3D. | Next.js |
| **ComparadorChaves** | Ferramenta que compara chaves de documentos XML com registros de uma base de dados; cerca de 2 mil notas conferidas. Desenvolvida em contexto profissional. | Python |
| **Invest** *(em desenvolvimento)* | Plataforma de acompanhamento e gerenciamento de investimentos. | Next.js e Nest.js |
| **Mini Blog** | Plataforma de publicação e gerenciamento de postagens. | React, Firebase |
| **Gerenciador de Pacientes** | Aplicação para gerenciamento de informações de pacientes. | Vue.js |
| **Orange Pi** | Orange Pi Zero 3 configurada com Pi-hole, para bloquear anúncios e rastreadores via DNS, e Unbound, como resolvedor DNS recursivo. | Armbian, Pi-hole, Unbound |

Cada projeto tem uma página própria no portfólio com mais informações, tecnologias utilizadas e, quando disponíveis, imagens, vídeos e links.
